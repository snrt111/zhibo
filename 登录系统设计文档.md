# 直播平台登录系统设计文档

## 一、登录方式概览

本平台支持三种登录方式：
1. **密码登录** - 传统的用户名+密码方式
2. **手机号验证码登录** - 使用手机号+短信验证码
3. **第三方登录** - 支持微信、QQ、微博OAuth2登录

## 三、登录原理详解

### 3.1 密码登录原理

#### 核心技术点：
1. **BCrypt密码加密**
   - 注册时：`password = BCrypt.encode(plainPassword)`
   - 登录时：`BCrypt.matches(plainPassword, storedHash)`
   - 特点：每次加密结果不同，自带盐值，防彩虹表攻击

2. **JWT Token生成**
   ```java
   String token = Jwts.builder()
       .setSubject(userId.toString())
       .claim("username", username)
       .claim("userType", userType)
       .setExpiration(new Date(System.currentTimeMillis() + 86400000))
       .signWith(SignatureAlgorithm.HS512, secretKey)
       .compact();
   ```

3. **Token存储与使用**
   - 前端存储：`localStorage.setItem('token', token)`
   - 请求携带：`Authorization: Bearer {token}`

#### 安全机制：
- 密码错误次数限制（可扩展）
- 账号状态检查（禁用账号无法登录）
- HTTPS传输加密

### 3.2 手机号验证码登录原理

#### 核心技术点：
1. **验证码生成与存储**
   ```java
   // 生成6位随机验证码
   String code = RandomStringUtils.randomNumeric(6);
   // 存储到Redis，5分钟过期
   redisTemplate.opsForValue().set("sms:code:" + phone, code, 5, TimeUnit.MINUTES);
   ```

2. **阿里云短信发送**
   ```java
   // 配置阿里云短信客户端
   Config config = new Config()
       .setAccessKeyId(accessKeyId)
       .setAccessKeySecret(accessKeySecret)
       .setRegionId(regionId);
   config.endpoint = "dysmsapi.aliyuncs.com";
   Client aliyunClient = new Client(config);
   
   // 发送短信
   SendSmsRequest request = new SendSmsRequest()
       .setPhoneNumbers(phone)
       .setSignName(signName)
       .setTemplateCode(templateCode)
       .setTemplateParam("{\"code\":\"" + code + "\"}");
   SendSmsResponse response = aliyunClient.sendSms(request);
   ```

3. **验证码验证**
   ```java
   String storedCode = redisTemplate.opsForValue().get("sms:code:" + phone);
   if (storedCode != null && storedCode.equals(inputCode)) {
       redisTemplate.delete("sms:code:" + phone); // 验证后删除
       return true;
   }
   ```

4. **发送频率限制**
   - 同一手机号1分钟内只能发送1次
   - 同一手机号1小时内最多发送5次

#### 安全机制：
- 验证码5分钟过期
- 验证码一次有效（验证后立即删除）
- 发送频率限制（1分钟1次，1小时5次）
- 支持开发环境模拟模式（不真正发送短信）

### 3.3 第三方OAuth2登录原理

#### OAuth2授权码模式流程：
```
1. 用户点击第三方登录按钮
2. 前端重定向到第三方授权页面
3. 用户确认授权
4. 第三方平台重定向回前端，携带code参数
5. 前端将code发送到后端
6. 后端使用code换取access_token和openid
7. 后端使用access_token获取用户信息
8. 后端根据openid和provider查询或创建用户
9. 后端生成JWT Token返回给前端
10. 前端存储Token，登录完成
```

#### 各平台配置示例：

**微信开放平台**：
```

授权URL: https://open.weixin.qq.com/connect/qrconnect

UserInfoURL: https://api.weixin.qq.com/sns/userinfo
```

**QQ互联**：
```

授权URL: https://graph.qq.com/oauth2.0/authorize
TokenURL: https://graph.qq.com/oauth2.0/token

```

**微博开放平台**：

## 四、阿里云短信配置

### 4.1 配置说明

在 `application.yml` 中添加以下配置：

```yaml
sms:
  aliyun:
    enabled: true                                    # 是否启用阿里云短信
    access-key-id: LTAI5t8xxxxxxxxxxxxx             # AccessKey ID
    access-key-secret: xxxxxxxxxxxxxxxxxxxxxxxxxxxx # AccessKey Secret
    region-id: cn-hangzhou                          # 区域ID
    sign-name: 您的签名                              # 短信签名（需要在阿里云后台审核通过）
    template-code: SMS_123456789                    # 短信模板CODE
```

### 4.2 环境变量配置

生产环境建议使用环境变量：

| 环境变量 | 说明 | 示例值 |
|----------|------|--------|
| SMS_ALIYUN_ENABLED | 是否启用 | true |
| SMS_ALIYUN_ACCESS_KEY_ID | AccessKey ID | LTAI5t8xxx |
| SMS_ALIYUN_ACCESS_KEY_SECRET | AccessKey Secret | xxxxx |
| SMS_ALIYUN_REGION_ID | 区域ID | cn-hangzhou |
| SMS_ALIYUN_SIGN_NAME | 短信签名 | 您的签名 |
| SMS_ALIYUN_TEMPLATE_CODE | 模板CODE | SMS_123456789 |

### 4.3 短信模板配置

在阿里云短信服务中创建模板，模板内容示例：

```
您的验证码是：${code}，请在5分钟内完成验证，切勿泄露给他人。
```

**注意**：模板变量名必须为 `code`，与代码中的 `templateParam` 对应。

### 4.4 获取AccessKey

1. 登录阿里云控制台：https://www.aliyun.com
2. 进入"AccessKey管理"页面
3. 创建新的AccessKey或使用现有AccessKey
4. 保存AccessKey ID和AccessKey Secret

### 4.5 开发模式

当 `sms.aliyun.enabled=false` 时，系统进入模拟模式：
- 不会真正发送短信
- 验证码会打印到控制台日志中
- 适用于开发和测试环境

**请求体**:

**接口**: `POST /api/user/send-sms-code`

```json
{
```

## 六、前端实现要点

### 6.1 登录状态管理

```typescript
// 存储登录状态
localStorage.setItem('token', token);
localStorage.setItem('userType', userType.toString());
localStorage.setItem('username', username);

// 检查登录状态
const token = localStorage.getItem('token');
const isLoggedIn = !!token;

// 退出登录
localStorage.removeItem('token');
localStorage.removeItem('userType');
localStorage.removeItem('username');
```

### 6.2 路由守卫

```typescript
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token');
  const userType = localStorage.getItem('userType');

  // 需要登录的页面
  if (to.meta.requiresAuth && !token) {
    next({ path: '/login', query: { redirect: to.fullPath } });
    return;
  }

  // 需要管理员权限的页面
  if (to.meta.requiresAdmin && userType !== '1') {
    next({ path: '/' });
    return;
  }

  next();
});
```

### 6.3 请求拦截器

```typescript
request.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```

## 七、安全建议

### 7.1 后端安全
1. **密码强度要求**：至少8位，包含大小写字母和数字
2. **验证码频率限制**：同一手机号1分钟内只能发送一次，1小时内最多5次
3. **登录失败限制**：连续5次失败后锁定15分钟
4. **Token刷新机制**：实现Access Token和Refresh Token分离
5. **HTTPS强制**：生产环境必须使用HTTPS

### 7.2 前端安全
1. **XSS防护**：对用户输入进行转义处理
2. **CSRF防护**：使用SameSite Cookie
3. **Token安全**：使用HttpOnly Cookie存储敏感Token
4. **输入验证**：前端进行基本的格式验证

### 7.3 第三方登录安全
1. **State参数**：使用随机State参数防止CSRF攻击
2. **回调域名白名单**：严格配置回调域名
3. **签名验证**：验证第三方平台返回的数据签名
4. **定期审核**：定期检查第三方登录日志

## 九、故障排查

### 9.1 常见问题

**问题1：验证码发送失败**
- 检查Redis服务是否正常运行
- 检查短信服务商API配置
- 检查手机号格式是否正确

**问题2：第三方登录回调失败**
- 检查回调域名是否在白名单中
- 检查AppID和AppSecret配置
- 检查网络是否能访问第三方平台

**问题3：Token验证失败**
- 检查JWT密钥是否一致
- 检查Token是否过期
- 检查请求头格式是否正确

### 9.2 日志监控

建议在生产环境添加以下日志：
- 用户登录时间、IP、设备
- 登录失败原因
- 验证码发送记录
- 第三方登录回调参数
